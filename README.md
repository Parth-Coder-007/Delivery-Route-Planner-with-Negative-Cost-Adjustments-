# Delivery Route Planner with Negative Cost Adjustments

## Description
This project is a delivery route planning system that finds an optimal
route while considering negative cost adjustments.

## Features
- Delivery route planning
- Cost calculation
- Negative cost adjustments
- Optimal route selection

## Technologies Used
- C++
- Graph Algorithms

## How to Run
1. Clone this repository.
2. Open the project in your IDE.
3. Compile the source code.
4. Run the program.
